# vae-lightstick

许嵩「安泊猜想」演唱会荧光棒的协议研究与复现记录

本次在南宁站带回的三支 `LED17_V5.6.31 2025.04.02` 样机上，用 Flipper Zero 完成了7／8号分组控制（荧光棒上的标签可识别，或者拆装电池后亮光默认白光的为7组，默认绿光的为8组）。

**本项目依托上游公开工作完成。** 感谢 [HansZ8 / EncoreLightSticks](https://github.com/HansZ8/EncoreLightSticks) 公开采样、协议说明和波形，感谢 [wuhan005 / LightStick](https://github.com/wuhan005/LightStick) 提供可工作的参考实现。

## 使用注意事项

> [!Warning]
> 本项目会通过 Flipper Zero 实际发射 **433.92 MHz 射频信号**。
>
>使用者应当核对当地的频段、发射功率和使用场景规定，只做近距离、低功率测试，避免在演出现场或可能干扰合法设备的环境中使用。

> [!Important]
在中国大陆，使用前还应注意：
>
>- **433 MHz 不是可任意发射的“免许可频段”。** 工信部明确说明，433.05–434.79 MHz 在部分欧洲国家属于指定的 ISM 应用频段，国内使用应遵守我国无线电管理规定。[工信部政策解读](https://www.miit.gov.cn/zwgk/zcjd/art/2020/art_7e6fe7b6653b411e9d9f0510df95e59d.html)。
>- **免许可有设备及用途条件。** 根据[工信部 2019 年第 52 号公告](https://www.miit.gov.cn/zwgk/zcwj/wjfb/gg/art/2020/art_4f2c890530cc4837b2113cf977e249c4.html)，只有列入并符合《微功率短距离无线电发射设备目录和技术要求》的设备，才适用免频率使用许可、免无线电台执照和免型号核准的规定。
>- **相关数值有明确适用范围。** 公告[附件第 3 页“（二）通用无线遥控设备”第 1 项](https://www.miit.gov.cn/cms_files/filemanager/oldfile/miit/n1146295/n1652858/n1652930/n4509607/c7545828/part/7545929.pdf#page=3)列出 433.05–434.79 MHz、发射功率不超过 **10 mW（e.r.p.，有效辐射功率）**、占用带宽不大于 **400 kHz**，并禁止用于无线控制玩具、模型等。符合频率和功率数值仍不足以单独认定适用该类别，还需核对用途、通用辐射发射要求等完整条件.
>- **不得造成有害干扰。** 不得擅自扩大发射频率范围、加大发射功率（包括外接功放）或更改发射天线；产生有害干扰时，应立即停止使用，消除干扰后再继续。机场等电磁环境保护区域、重大任务期间及无线电管制期间还须遵守相应规定。见上述公告第二、四、五、九条。

## Flipper Zero

本次使用固件为 **Unleashed `unlshd-094e`**。研究目录中的 JS 脚本需要 `subghz` JavaScript 模块；网页控制台使用配套的 [FZ 原生应用](native/README.md)，当前按 **F7 API `88.19`** 编译。其他固件或版本尚未完成兼容性验证。

## 网页控制台

[web/](web/README.md) 是基于 Vue 的网页控制台，支持 Web Serial 与 WebUSB，通过 USB 直连 Flipper Zero。支持 G1–G8 分组开关、各组独立配色、G7／G8 双色预设、自动关灯和独立的全部关灯按钮。实时模式沿用当前分组选择，以已选组白光开始，可用鼠标划过或手指拖过调色盘，选择单组调色或统一操控；调色期间手动关灯，关闭实时模式时也会尝试发送全部关灯指令。详细运行方式、通信延迟与文件说明见 [web/README.md](web/README.md)。

连接时会检查并按需安装原生应用，然后发送短颜色命令，由 FZ 在内存中生成波形。相同 3 帧配置下，本机 USB CLI 测速由旧路径约 1.57 秒／次改善到约 **216 ms／次（4.63 次／秒）**；测速范围与构建说明见 [native/README.md](native/README.md)。功率仍固定为原来的 `PA=07`。

构建环境使用 **Node.js 24.22.2** 和 **npm 12.2.1**；Node 版本记录在 `web/.node-version`。

```sh
cd web
npm install --global npm@12.2.1
npm ci
npm run dev
```

用桌面版 Chrome 或 Edge 打开终端中的 localhost 地址，再点击“连接 Flipper”。

## 协议结构与发射配置

下面的报文结构与时序已在样机上跑通。当前生成器使用固定低功率的自定义射频预设。

| 参数 | 当前配置 |
| --- | --- |
| 载波 | 433.92 MHz |
| 调制 | OOK，用载波的开／关传递数据 |
| 波形表示 | 研究生成器输出 Flipper SubGhz RAW；原生应用在内存中生成高／低电平游程 |
| 射频预设 | `FuriHalSubGhzPresetCustom`，保留原 Ook650 寄存器配置，仅调整功率表 |
| 固定功率参考档 | 近似 −25 dBm，约 0.0032 mW；实际辐射功率未测量 |
| 数据编码 | Manchester，MSB first |
| 半位宽 | 250 us |
| 同步低电平 | 1000 us |
| 帧间额外间隔 | 0，连续发送 |
| 扩展数组长度 | 16 字节 |
| 单周期 | 65.5 ms |

`FuriHalSubGhzPresetOok650Async` 是 FZ 内置预设的名称：`OOK` 表示开关键控，`650` 表示接收滤波器带宽约 650 kHz，`Async` 表示按外部时序异步输入／输出数据。

当前使用同一组射频寄存器值，改用自定义预设将 CC1101 的 `PATABLE[1]` **固定为 `07`**；`PATABLE[0]` 保持 `00`，用于关闭载波。该设置在 [TI DN013 第 9 页表 2](https://www.ti.com/lit/an/swra151a/swra151a.pdf#page=9)中的典型值为 **−25.3 dBm**，本文以近似 −25 dBm／0.0032 mW 称呼。最初的协议实测使用内置 Ook650 预设，低功率对照另记于下文。射频配置来源见 [THIRD_PARTY_NOTICES.md](research/THIRD_PARTY_NOTICES.md#flipper-zero-射频配置)。

每个分组的颜色用 8 bit表示：从高位到低位，蓝、绿、红各占 2 bit，最后 2 位固定填二进制 `11`。输入仍使用常见的 RGB 数值，每个分量为 `0～255`；编码时将每个分量除以 64 后向下取整，转换为 `0～3` 四个档位，再填入对应位置。

| 颜色 | 输入 RGB | 按 `BB GG RR TT` 拼接 | 完整二进制 | 十六进制 |
|---|---|---|---|---|
| 关闭 | `(0, 0, 0)` | `00 00 00 11` | `00000011` | `03` |
| 红 | `(255, 0, 0)` | `00 00 11 11` | `00001111` | `0F` |
| 绿 | `(0, 255, 0)` | `00 11 00 11` | `00110011` | `33` |
| 蓝 | `(0, 0, 255)` | `11 00 00 11` | `11000011` | `C3` |
| 白 | `(255, 255, 255)` | `11 11 11 11` | `11111111` | `FF` |

**以下位置从 1 开始计数：**

```text
G1 G2 G3 G4 G5 G6 G7 00 00 00 K1 G8 K2 03 03 K3
```

| 字节 | 含义或当前处理 |
| --- | --- |
| 1～7 | 七组颜色位置；第 7 字节 G7 对应本次两支 7 号 |
| 8～10 | 旧附加字段，本方案固定为 `00 00 00` |
| 11 | K1，校验前 10 字节 |
| 12 | 第八组颜色，对应本次 8 号 |
| 13 | K2，校验前 12 字节|
| 14～15 | 保留 `03 03`，用途与分组映射未确认 |
| 16 | K3，覆盖前 15 字节 |

每处校验都将此前各字节的高、低半字节全部 XOR，再 XOR `0xD`，最后与 `0x80` 合并。

发送线序沿用上游实现：先发数组末两字节，再发同步低电平、一个 Manchester 0、数组其余正文。循环观察两个同步点之间时，下一周期的末两字节补齐完整数组。正文必须使用 `packet[:-2]`，不能把长度写死为旧格式的 11 字节。

## 实测范围与研究过程

样机仅有两支标 7、一支标 8，板号均为 `LED17_V5.6.31 2025.04.02`，Flipper Zero 发射后都额外发送一次关闭：

| 实验 | 实际观察 |
| --- | --- |
| 发送第 7 字节红色 | 两支 7 号红后关闭，8 号无变化 |
| 扩展追加字段红，电池不动 | 8 号从灭变红，再关闭 |
| 发送第 7 字节红色，第 12 字节蓝，其余追加位置为关 | 两支 7 号红、8 号蓝，随后全灭 |
| 只给第 12 字节绿 | 仅 8 号亮绿约两秒，随后全灭 |

第 14／15 字节没有完成分组映射，无法确定是否支持其他区域。其他标签、板号、场次、批次或固件均未测试。
