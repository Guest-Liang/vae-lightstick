# 网页灯光控制台

Vue + TypeScript 单页应用，通过浏览器的 Web Serial API 直连 Flipper Zero。没有 Python 服务端，不需要在网页和 FZ 之间再运行一个本地代理。

## 本地运行

需要 **Node.js 24 LTS**、**npm 12.2.1 或更新版本**，以及桌面版 Chrome 或 Edge。

本项目固定使用 **Node.js 24.22.2**，版本记录在 `.node-version`；`package.json` 的 `engines.node` 限定为 `^24.22.2`，`packageManager` 记录 `npm@12.2.1`。

在本目录运行：

```sh
npm ci
npm run dev
```

打开终端显示的 <http://localhost:5173>。使用支持数据传输的 USB 线连接开机的 FZ，插好 microSD 卡，退出 FZ 上的其他应用并关闭占用串口的 qFlipper／其他网页，然后点击“连接 Flipper”。在浏览器弹窗中选择 FZ。

需要固件提供 CLI `js` 命令以及 `subghz` JavaScript 模块。连接时会读取 `device_info`、检查 SD 卡、准备控制文件并运行一个只加载模块的探测脚本；收到有效回复后才显示已连接，连接本身不会发射信号。

## 使用

- **分组开关**：默认选择 G7、G8。打开表示参与本次调色，关闭表示不参与；开关本身不会发送无线信号。“展开全部 8 个分组”可以控制 G1–G8。
- **调色**：直接展示协议支持的 64 种颜色，不提供连续 RGB 滑块、HEX 输入或任意取色器。每个分量只取 `0 / 85 / 170 / 255`，分别对应协议中的 `0 / 1 / 2 / 3` 档。点击色块只更新选中组的配色草稿，黑色表示关闭。
- **我的双色**：内置红蓝、蓝红、紫青、双白四个 G7／G8 组合。点击后选择 G7、G8 并载入配色，仍需要点击“发送颜色”才会发射。其他组保留此前已发送的目标色。
- **发送颜色**：上传本次波形并调用 FZ 发送，默认约 2.096 秒后追加所选组的关闭帧。不选自动关灯时，发送结束后灯棒可以继续保持颜色；停止发射本身不会熄灯。
- **全部关灯**：与分组开关无关，发送完整八组关闭帧及旧七组关闭帧。关闭全部分组开关后仍能使用。
- **断开连接**：释放 USB 串口，不额外发送关灯。网页不会在连接、调色、选择预设或切换分组时自行发射。

每次发送和关灯都要等 FZ 返回脚本完成结果，期间操作按钮会暂时禁用。它是上传文件后执行脚本的方式，因此没有拖动滑块即实时连续发射，也不需要一直占用无线电来维持颜色。

### “不控制该组”的具体含义

当前协议每一帧都包含完整的八组颜色，没有已知的“跳过某组”字段。网页会记住本次连接使用期间各组上次发送的目标色；发送新配色时，没有选中的组沿用这个值，自动关灯也只改变本次选择的组。首次打开网页时，这些记忆值均为关灯。

这份记忆无法读取灯棒被其他控制器设定的颜色，也不是灯棒当前状态。关闭分组开关不会立即熄灯，但后续发送仍然包含这个分组的颜色。网页与灯棒之间没有状态回传，界面中的“已发送”表示 FZ 报告执行成功。

配色草稿与已发送目标色分开保存：自动关灯或“全部关灯”之后，草稿仍在，可以直接再次发送同一个组合。刷新页面会重置草稿、选择和已发送目标色的记忆。

## 通信与设备文件

```text
Vue 页面 → Web Serial / USB CDC → FZ CLI
         → storage write_chunk 写入 RAW 与 JS
         → js 运行脚本 → subghz.transmitFile → 荧光棒
```

网页使用 `433920000 Hz`、OOK650 RAW、250 µs Manchester 半位宽、1000 µs 同步低电平，以及本项目恢复的 16 字节格式。颜色文件含 32 帧；自动关灯文件含 16 帧；全部关灯额外发送 8 帧旧格式关闭序列。网页代码不会修改固件、自动电源设置或频段限制。

运行时只在 FZ 的 `/ext/subghz/vae-lightstick-web/` 下创建／覆盖以下文件，不依赖 `research/example-generate.py` 的输出目录：

| 文件 | 用途 |
| --- | --- |
| `probe.js` | 检查 JavaScript 模块能否加载，不发射 |
| `off.sub` | 完整八组关闭波形 |
| `legacy-off.sub` | 旧七组关闭波形 |
| `color.sub` | 本次完整八组颜色波形，每次发送更新 |
| `after.sub` | 本次自动关灯后的完整八组波形，按需要更新 |
| `auto.js` | 发送颜色，随后发送 `after.sub` |
| `hold.js` | 仅发送颜色 |
| `off.js` | 依次发送完整格式与旧格式关闭波形 |

结束后这些文件会保留在 SD 卡。网页下次连接会重新准备公共控制文件。设备睡眠、拔线、写入错误或回复超时后，页面会报告问题并释放串口，不会在后台自动重发。

## 构建

```sh
npm run build
npm run preview
```

`build` 先对 TypeScript 业务与通信代码进行类型检查，再编译 Vue 模板并输出静态文件到 `dist/`。可以部署到 HTTPS 静态站点，包括子路径。Web Serial 需要安全上下文：本地使用 localhost，远程部署使用 HTTPS；直接双击 HTML 或通过普通 HTTP 局域网地址访问不适合作为串口入口。浏览器使用要求见 [MDN Web Serial API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Serial_API)。

| `src/controller.ts` | 本项目编写的分组选择、配色草稿、已发送目标色、双色预设和页面交互逻辑 |

| `src/main.ts`、`index.html` | Vue 应用入口 |
| `vite.config.ts`、`tsconfig.json`、`src/vue.d.ts` | 本地开发、静态构建、类型检查配置，以及 Vue 文件导入声明 |
| `package.json`、`package-lock.json` | 运行命令、精确版本与安装依赖树 |
